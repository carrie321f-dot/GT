# TaskPlus：加強版 Google Tasks

單一檔案（`index.html`）網頁 app，直接同你嘅 Google Tasks 雙向同步，冇第三方 server。

## 功能（Todoist 風格）

- **側欄**：搜尋、收件匣、今日、即將到期、標籤、專案
  - 收件匣 = Google Tasks 預設清單；專案 = 你其他嘅 Google Tasks 清單，新增 / 改名 / 刪除都會同步
- **快速新增**（任務名稱入面直接打）：
  - 日期：`今日` `明日`（或 `聽日`）`後日` `3日後` `下星期一` `星期五` `12月25日` `2026-12-25`，英文 `tomorrow` `next mon` `25 dec` 都得
  - 優先度：`p1`（最高，紅）、`p2`（橙）、`p3`（藍）、`p4`（無）
  - 標籤：`@工作`　專案：`#家庭`（`#收件匣` 就放返收件匣）
  - 例：`交報告 下星期一 p1 @工作 #工作`
- **多層子任務**：無限層、可摺疊，顯示完成進度（1/3）；hover 任務會出現「新增子任務 / 編輯 / 刪除」
- **任務詳情**：改標題、描述、日期、優先度、標籤、移去另一個專案、改上層任務、管理子任務
- **搜尋**：標題、描述、標籤即時搜尋
- **習慣追蹤**：每日 / 逢星期幾 / 每週 N 次三種頻率；一撳打卡，可補打卡過去 7 日；顯示連續日數（每週型顯示連續週數）、最長連續、近 30 日完成率，仲有 20 週打卡熱圖
- **統計**（7 / 30 / 90 日）：完成任務數、日均、連續完成日數、逾期數；每日完成任務圖表、專案進度、習慣完成率、邊日最高效、活躍熱圖；圖表可切換成表格睇數字
- **專案進度**：每個專案頁頂部都顯示已完成 x/y 同百分比
- **習慣月曆**：習慣頁可切換「清單 / 月曆」，月曆每日顯示各習慣打卡點（實心 = 已打卡、空心 = 漏咗），全部完成嘅日子會標綠；撳日子可睇當日習慣同完成嘅任務，亦可補打卡。每個習慣詳情亦有自己嘅月曆（同近 20 週熱圖）
- **自選外觀**：側欄底部 ⚙ 可揀淺色 / 深色 / 跟隨系統，主題色有 8 款預設加自選顏色；專案同習慣都可以自選顏色（專案頁撳 ✎）
- **快捷鍵**：`q` 新增任務，`/` 搜尋
- 有到期日嘅任務會自動出現喺 Google 日曆（Google 只支援日期，唔支援時間）
- 自動跟系統深色 / 淺色模式

## 設定（只需一次）

1. 去 https://console.cloud.google.com 開新 Project
2. 「API 和服務」→「程式庫」→ 啟用 **Google Tasks API**
3. 「OAuth 同意畫面」→ External，保持 Testing 狀態，喺 **Test users** 加你自己個 Gmail
4. 「憑證」→ 建立憑證 → OAuth 用戶端 ID → **網頁應用程式**
5. 「已授權的 JavaScript 來源」加 `http://localhost:8000`（或你部署嘅網址）
6. 複製 Client ID

## 執行

```
cd 呢個資料夾
python3 -m http.server 8000
```

開 http://localhost:8000 ，貼上 Client ID，用 Google 登入。
（唔可以直接雙擊開 `index.html`，Google 登入要 http(s) 網址。）
你亦可以放上 GitHub Pages / Netlify，記得將佢個網址加入「已授權的 JavaScript 來源」。

## 安裝去手機（PWA）

PWA 要 **https** 網址先裝得到，手機連唔到你電腦嘅 localhost，所以要先部署（免費）：

1. 將成個資料夾（`index.html`、`manifest.json`、`sw.js`、`icons/`）放上 GitHub Pages / Netlify / Cloudflare Pages 等靜態空間
2. 將部署後嘅網址（例如 `https://你的名.github.io`）加入 OAuth Client ID 嘅「已授權的 JavaScript 來源」（只要網域，唔使加路徑）
3. 手機瀏覽器開嗰個網址並登入
   - **Android Chrome**：選單 →「安裝應用程式」／「加至主畫面」
   - **iPhone Safari**：分享 →「加入主畫面」
4. 之後由主畫面圖示開，就似原生 app 咁全螢幕

離線時會顯示上次同步嘅資料，但唔可以改；有網絡後會自動同步。
更新 app 後如果手機冇即時變，閂咗再開一次。

## 資料點存

Google Tasks 冇標籤同優先度欄位，所以 TaskPlus 將呢啲資料放喺任務**備註最尾**，格式係：

```
[[tt:{"tags":["工作"],"pri":2}]]
```

喺 Google Tasks / 日曆入面你會見到呢行字，唔好刪走佢，否則標籤會冇咗。
深於一層嘅子任務，喺 Google 本身會顯示成同一層，只有 TaskPlus 會顯示完整層級。

## 習慣同統計嘅資料存喺邊

- 習慣資料存喺你 Google Tasks 入面一個叫 **「_TaskPlus 資料」** 嘅清單（第一次新增習慣時自動建立），每個習慣係一個任務，打卡紀錄壓縮存喺備註。所以手機同電腦會自動同步。**請勿刪除或改名呢個清單**；TaskPlus 會將佢隱藏，唔會出現喺專案入面。
- 主題色同專案顏色存喺同一個清單入面一個叫 `__settings` 嘅任務，所以會同步到所有裝置；淺色 / 深色模式只存喺呢部裝置。
- 統計用 Google Tasks 記錄嘅「完成時間」，喺 TaskPlus 或 Google 其他 app 完成嘅任務都計。已刪除嘅任務、冇完成時間嘅舊任務唔會計入。

## 限制

- 唔支援離線編輯（有網絡先可以改）
- 同步方式係「後改嘅贏」；兩部裝置同一時間改同一個習慣嘅打卡，後儲存嗰個會覆蓋，每 90 秒及切換返分頁時會自動拉取最新資料
- 登入 token 約 1 小時過期，過期後會自動靜默更新，失敗就要再按登入
- Testing 狀態嘅 OAuth app 登入時會見到「未經驗證」警告，係正常嘅（只有你自己用）
