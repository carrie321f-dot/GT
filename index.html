TaskPlus

加強版 Google Tasks：分類、標籤、優先度、搜尋、多層子任務，全部同步返 Google Tasks（Google 日曆都睇到）。

第一次用？點樣攞 Client ID
  1. 去 console.cloud.google.com 開一個新 Project。
  2. 「API 和服務」→「程式庫」→ 啟用 Google Tasks API。
  3. 「OAuth 同意畫面」→ 揀 External，Publishing status 保持 Testing，喺 Test users 加你自己嘅 Gmail。
  4. 「憑證」→ 建立憑證 → OAuth 用戶端 ID → 類型 網頁應用程式。
  5. 「已授權的 JavaScript 來源」加 http://localhost:8000（或你部署嘅網址）。
  6. 複製 Client ID 貼上面。

用 python3 -m http.server 8000 喺呢個檔案所在資料夾開 server，然後瀏覽 http://localhost:8000。
