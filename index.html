TaskPlus

加強版 Google Tasks：收件匣、今日、即將到期、專案、標籤、優先度、多層子任務，全部同步返 Google Tasks（Google 日曆都睇到）。

第一次用？點樣攞 Client ID
  1. 去 console.cloud.google.com 開一個新 Project。
  2. 「API 和服務」→「程式庫」→ 啟用 Google Tasks API。
  3. 設定 OAuth 同意畫面：對象揀「外部」，保持測試中，喺「測試使用者」加你自己嘅 Gmail。
  4. 「憑證」→ 建立憑證 → OAuth 用戶端 ID → 類型 網頁應用程式。
  5. 「已授權的 JavaScript 來源」加你部署嘅網域（例如 https://你的名.github.io）。
  6. 複製用戶端 ID 貼上面。
